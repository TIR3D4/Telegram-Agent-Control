# راهنمای فارسی Telegram Agent Control

## گفتگوی مستقل روی گوشی

در شاخهٔ `engineering/mobile-assistant`، بخش **دستیار گفتگو** به پنل اضافه شده است. ارائه‌دهنده، مدل و کلید API را از فرم وب تنظیم کنید. کلید فقط رمزگذاری‌شده روی سرور نگهداری می‌شود و هزینهٔ API جدا از اشتراک ChatGPT است. عملیات Telegram با مجوز محدود آماده می‌شوند و انتشار نیازمند تأیید مستقل مالک است.

این مسیر به گزینهٔ ثبت custom MCP در حساب ChatGPT نیاز ندارد و اتصال را به همین گفتگوی ChatGPT اضافه نمی‌کند. نبودن گزینهٔ ثبت یا برچسب Desktop only با تغییر manifest یا پروکسی حل‌شده فرض نمی‌شود.

[راهنمای استفاده و دستور ارتقای یک‌مرحله‌ای](MOBILE_ASSISTANT.md) · [مقایسهٔ کد پروژه‌های مرجع](MOBILE_ASSISTANT_RESEARCH.md) · [نتایج واقعی تست‌ها](MOBILE_ASSISTANT_TEST_RESULTS.md)

دستیار داخل پنل، درخواست توسعه را به پیشنهاد قابل‌بررسی تبدیل می‌کند؛ عامل خودکار کدنویسی یا استقرار ندارد. توسعه روی شاخهٔ جدا، تست و PR انجام می‌شود و ارتقای سرور از مسیر محدود مالک است.

## ورود از گوشی و اتصال هوش مصنوعی

در نسخهٔ ۰٫۳، نصب‌کننده نام کاربری و رمز را یک‌بار می‌گیرد. پنل در مرورگر گوشی و کامپیوتر باز می‌شود. از بخش **Connect an AI** کلید API محدود بسازید و لینک API، راهنما و کلید را به سرویس هوش مصنوعی دارای ابزار HTTP بدهید. برای MCP، اتصال OAuth از همین پنل ساخته می‌شود؛ رمز پنل را به هوش مصنوعی ندهید.

ارتقا: `bash scripts/tacctl update`. اطلاعات و تنظیمات قبلی پشتیبان‌گیری می‌شوند؛ پس از ارتقا اجرای عملیات موقتاً متوقف است تا صاحب حساب بررسی و ادامه دهد. برای اولین ارتقا از نسخهٔ قدیمی، دستور دریافت اسکریپت جدید در [راهنمای اتصال](CONNECTIONS.md) آمده است.

برچسب **Desktop only** متعلق به اتصال ثبت‌شده در ChatGPT است. ZIP دارای آدرس MCP به‌تنهایی اتصال ابری ایجاد نمی‌کند. باید از **Add custom MCP server** سرور را ثبت کرد؛ سپس بستهٔ متصل به شناسهٔ واقعی برنامه را از پنل دانلود کرد. پشتیبانی گوشی در حساب ChatGPT باید بعد از اتصال آزمایش شود.


این پروژه رابط مدیریت تلگرام برای Agent و مالک کانال است: API مستند، کنسول وب، صف اجرای ماندگار، تأیید انتشار، زمان‌بندی و کاتالوگ تصویری ایموجی.

نسخهٔ ۰.۲ شامل رجیستری ۱۸۵ متد و ۴۰۰ نوع دادهٔ Bot API 10.3 است. پوشش schema و انتقال درخواست به معنی تست زندهٔ تمام قابلیت‌ها یا داشتن همهٔ مجوزهای تلگرام نیست.

## نصب

```bash
git clone --branch engineering/production-hardening-v0.2 https://github.com/TIR3D4/Telegram-Agent-Control.git
cd Telegram-Agent-Control
./scripts/install.sh
```

توکن ربات مخفی وارد می‌شود. نام کانال‌ها یا شناسه‌های عددی مجاز را مشخص کنید. اگر دامنه دارید، DNS آن را به سرور متصل کنید تا Caddy گواهی HTTPS بگیرد. بدون دامنه، پنل روی localhost پورت 8787 اجرا می‌شود و با SSH tunnel قابل دسترسی است.

کلید مالک داخل `.env` خصوصی است. پس از ورود به پنل، از بخش Agent permissions برای هر Agent دسترسی محدود و زمان‌دار بسازید. کلیدهای مشترک قدیمی در نصب جدید غیرفعال‌اند. کلید مالک را به Agent ندهید.

۴۲ ابزار MCP، دسترسی بر اساس کانال/متد/منبع، لغو و چرخش کلید، تأیید زمان‌دار، بررسی بکاپ و پنل‌های جدید اضافه شده‌اند. OAuth به سرویس هویت خارجی نیاز دارد؛ اتصال واقعی حساب ChatGPT هنوز جزو تست‌های انجام‌شده نیست. گزارش دقیق در [TEST_RESULTS](TEST_RESULTS.md) و محدودیت‌ها در [KNOWN_LIMITATIONS](KNOWN_LIMITATIONS.md) است.

## روال استفاده

۱. در API explorer درخواست `getMe` و سپس `getChatMember` بسازید و نتیجهٔ واقعی را ببینید.
۲. در Compose، قالب پیام و JSON را تنظیم و فایل را بارگذاری کنید.
۳. درخواست را اعتبارسنجی و ذخیره کنید. پیام نوشتنی ابتدا draft است.
۴. مالک همان نسخه را تأیید می‌کند؛ Worker در زمان تعیین‌شده اجرا می‌کند.
۵. نتیجه، لینک پیام و علت خطا در Operations و Activity دیده می‌شود.

آلبوم معمولی و اسلاید واقعی Rich Message هر دو از API قابل ارسال‌اند. شکل دقیق را در کانال آزمایشی بررسی کنید. انتخاب ایموجی هم بر اساس تصویر preview و برچسب‌های ثبت‌شده است، نه صرفاً عدد شناسه.

## مدیریت سرور

`./scripts/tacctl` منوی نصب، وضعیت، لاگ، شروع/توقف، تنظیمات، به‌روزرسانی، پشتیبان‌گیری و حذف را باز می‌کند. حذف عادی اطلاعات را نگه می‌دارد. پاک‌سازی کامل داده‌ها فرمان جداگانه و تأیید تایپی دارد.

اتوماسیون روی VPS اجرا می‌شود و به باز بودن چت وابسته نیست. Agent بیرونی از REST یا MCP وصل می‌شود؛ این نسخه خودش مدل زبانی را اجرا نمی‌کند. برای اتصال ChatGPT یا هر کلاینت، سازگاری روش احراز هویت MCP باید جداگانه بررسی شود.

در وضعیت `uncertain`، احتمال دارد تلگرام پیام را دریافت کرده ولی پاسخ به سرور نرسیده باشد. ابتدا کانال و لاگ را بررسی کنید و سپس وضعیت را تطبیق دهید؛ ارسال مجدد خودکار انجام نمی‌شود.
